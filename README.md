# Question Answering System using Transformers
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1aDL346Xhg9weffGON3lsMDl5BWQw5nV-?usp=sharing)

This project demonstrates a Question Answering (QA) system built using Hugging Face Transformers.  
The model takes a context paragraph and a question as input, then predicts the most relevant answer.
This project uses a transformer-based model to answer questions from a given context. It demonstrates the power of NLP and pre-trained models in extracting meaningful information from text.
